## Installation iPhone
1. Décompresser le dossier sur un hébergement HTTPS statique (GitHub Pages, Netlify, Cloudflare Pages, Vercel...).
2. Ouvrir l’URL dans Safari.
3. Partager > Ajouter à l’écran d’accueil.
4. Lancer Lautrec depuis l’icône.

## Important
Une PWA ne peut pas être installée directement depuis un ZIP local sur iOS. Elle doit d’abord être servie via HTTPS.
