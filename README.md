# Lautrec — Les Mémoires de l’Ombre V3 RPG

PWA iPhone jouable hors ligne après la première ouverture.

## Nouveautés V3
- Campagne principale multi-chapitres
- Mode monde ouvert après le premier grand arc
- Actions libres interprétées localement
- Combats tactiques au tour par tour
- Compagnons recrutables : Mira, Elias, Valeria
- PV individuels des compagnons
- Inventaire et raretés d’équipement
- Équipement actif
- Marchand et économie en or
- Blessures durables
- Réputation et factions
- Moralité / choix moraux
- Relations avec les compagnons
- Quêtes principales et secondaires procédurales
- Événements mondiaux persistants
- Plusieurs fins/branches possibles
- Carte, secrets, journal, XP, niveaux
- Sauvegarde locale
- Mode PWA installable
- Cache hors ligne via Service Worker

## Installation iPhone
1. Décompresser le dossier sur un hébergement HTTPS statique (GitHub Pages, Netlify, Cloudflare Pages, Vercel...).
2. Ouvrir l’URL dans Safari.
3. Partager > Ajouter à l’écran d’accueil.
4. Lancer Lautrec depuis l’icône.

## Important
Une PWA ne peut pas être installée directement depuis un ZIP local sur iOS. Elle doit d’abord être servie via HTTPS.
